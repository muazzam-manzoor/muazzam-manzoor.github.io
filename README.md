# Muazzam Manzoor — Developer Portfolio

A responsive personal portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and lucide-react.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```

The build creates a static export in `out/` for GitHub Pages. Project, skill, and experience content is maintained in `data/`; reusable page sections are in `components/`. Future technical notes belong in `content/insights/`; the portfolio intentionally shows no article cards until real articles are ready.
